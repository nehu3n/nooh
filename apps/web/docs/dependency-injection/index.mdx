---
title: Dependency Injection
description: Declare services, assign scopes, and let the compiler wire them into your handlers at build time.
---

Nooh's dependency injection system is purely compile-time. You declare services in containers, the compiler builds a dependency graph and validates it, and the generated route modules wire exactly the right dependencies into each handler — nothing more.
