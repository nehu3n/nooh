---
title: Nooh Documentation
description: A zero-dependency, compile-time metaframework for building type-safe file-based Hono APIs.
---

Nooh adds a **filesystem-first development model** on top of [Hono](https://hono.dev). Your files define the shape of your API, and a fast compiler generates the typed route functions and native Hono application behind them — with zero runtime overhead and full type safety.
