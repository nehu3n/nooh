title: Routing
description: How Nooh maps your filesystem to HTTP routes — static paths, dynamic segments, groups, and more.
---

Nooh's routing system derives your API's structure from the layout of files in your `routes` directory. Each file is one route endpoint; its path determines the URL and its name suffix determines the HTTP method.
